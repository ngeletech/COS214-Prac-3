Detailed Description

Represents a low-intensity ride for children that pasues on capacity alerts to manage queues.

WaterRide acts as a Leaf(an individual EventComponent object with no children) in the Composite Pattern Observer(receiving notices from a higher-level subject) in the Observer Pattern
